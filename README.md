# Equity-Research-Dashboard-DCF-Risk-Portfolio-Optimization-
Python-based equity research and portfolio analytics dashboard using Monte Carlo simulation, DCF valuation, risk metrics, and mean-variance optimization with interactive financial visualizations.

Equity Research & Portfolio Analytics Dashboard

This project is a single-file Python research program designed to simulate the kind of quantitative and strategic analysis used in equity research, portfolio management, and industry analysis roles.

Using Python, NumPy, Pandas, and Matplotlib, this project integrates valuation modeling, risk analysis, forecasting, and portfolio optimization into one analytical dashboard.

Objective

The objective of this project is to demonstrate how quantitative tools can support investment decision-making by:

Estimating asset return and risk behavior
Forecasting future stock prices using simulation
Valuing firms using discounted cash flow (DCF) methods
Constructing an optimal portfolio using modern portfolio theory
Visualizing results in a research-oriented dashboard format
Methodologies Implemented
1. Simulated Market Data Generation

We generated correlated returns for three representative assets:

FintechA
BankB
TechC

Using a multivariate normal distribution, the model simulates realistic co-movements among assets.

Output:
Daily return series
Historical price paths
Correlation structure between assets
Interpretation:

This creates a synthetic market environment for testing investment strategies and observing how different assets behave under shared market conditions.

2. Risk & Performance Metrics

For each asset, the model calculates:

Annualized Return
Annualized Volatility
Sharpe Ratio
